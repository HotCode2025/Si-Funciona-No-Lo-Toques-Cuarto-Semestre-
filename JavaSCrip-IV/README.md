---

## Resumen de clases

### Clase 1 - Estructura inicial del e-commerce

En la primera clase se armó la base del proyecto. Se trabajó con:

- HTML para estructurar la página
- CSS para definir el diseño visual
- JavaScript para cargar productos dinámicamente
- Un array de productos con nombre, precio, imagen y cantidad
- Renderizado de los productos en pantalla mediante JavaScript

Se aprendió a mostrar la información desde datos y a dibujar los elementos visualmente en la interfaz.

### Clase 2 - Carrito y modal

En la segunda clase se avanzó hacia la interacción del usuario. Se incorporaron:

- Botones de compra para cada producto
- Un array `cart` para guardar los productos seleccionados
- Lógica para agregar elementos al carrito
- Modal con overlay para mostrar el contenido del carrito
- Separación de responsabilidades por archivos (`products.js`, `index.js`, `cart.js`)

También se reforzó el uso de eventos, objetos y manipulación del DOM para crear una experiencia más completa de compra.

---

## Progreso del proyecto

La clase 1 sentó la base visual y de datos del e-commerce, mientras que la clase 2 agregó la funcionalidad principal del carrito. De esta forma, el proyecto va creciendo paso a paso y queda documentado el avance realizado por el grupo.

## Conclusión

El trabajo realizado por Los Sin Chamba demuestra la progresión del aprendizaje en JavaScript, desde la carga inicial de productos hasta la creación de una tienda con interacción y carrito. Cada clase aporta conceptos clave que permiten avanzar hacia una aplicación web más funcional y dinámica.
