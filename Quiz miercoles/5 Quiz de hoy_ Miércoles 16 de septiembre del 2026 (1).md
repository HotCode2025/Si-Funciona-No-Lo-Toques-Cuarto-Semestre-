**2\. En programación un código podría ser optimizado, hacerlo más limpio y escalable a largo plazo, haz una definición del significado de ESCALABILIDAD dentro de este contexto. Debes ampliar la respuesta investigando**

**En el contexto del código, la escalabilidad es la capacidad que tiene un sistema o bloque de código para manejar un crecimiento continuo de trabajo de manera fluida, preparándolo para ser ampliado sin perder calidad ni rendimiento.**

**Significa que si el proyecto crece —por ejemplo, si tenés que agregar nuevas funcionalidades, si el sistema pasa a soportar muchos más usuarios de golpe, o si tiene que procesar un volumen de datos mucho mayor— el código está preparado para soportar ese crecimiento. Lo fundamental acá es que lograr esto no te obliga a reescribir todo el sistema desde cero ni termina "rompiendo" lo que ya funcionaba bien.**

**Para que esto sea posible, se aplican buenas prácticas que hacen que el código sea limpio y optimizado, como:**

* **Desacoplamiento: Consiste en dividir el código en módulos independientes para que, si tocás o cambiás una parte, no afecte a las demás.**  
* **Patrones de diseño: Es apoyarse en soluciones que ya están probadas para resolver problemas de arquitectura y que ayudan a que el proyecto crezca de forma ordenada.**  
* **Evitar la "deuda técnica": Significa escribir código limpio (Clean Code) desde el minuto uno. Es, en el fondo, programar con empatía para que otros colegas (o vos mismo en un par de meses) puedan entender y modificar ese código fácilmente.**

**Referencia bibliográfica: Todo este marco de trabajo y sus reglas están profundamente detallados en el libro *"Clean Code: A Handbook of Agile Software Craftsmanship"* de Robert C. Martin ("Uncle Bob"). Esta obra es considerada fundamental en la industria para entender cómo la deuda técnica frena el crecimiento y brinda las pautas exactas para mantener un código legible, mantenible y verdaderamente escalable.**
